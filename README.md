# PasswordGeneratorAndAnalyzer
# 🛡️ CyberSecurity Suite: Password Analyzer & Generator

An advanced, client-side web application designed for ethical hacking and password security assessment. Built with a modern **Cyberpunk UI**, it allows users to evaluate password strength with simulated brute-force cracking speeds and securely generate robust passwords.

[![Live Demo](https://img.shields.io/badge/Live-Demo-00ff88?style=for-the-badge&logo=rocket)]((https://shakra000.github.io/PasswordGeneratorAndAnalyzer/))
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg?style=for-the-badge)](LICENSE)

---

## ✨ Features

* **Password Strength Analyzer:** 
  * Real-time security scoring and visual progress meters.
  * **Simulated Crack Time Estimation:** Calculates estimated time to crack passwords across different hardware architectures:
    * Standard CPU (Single Thread)
    * High-end GPU Rigs (e.g., RTX 4090)
    * Quantum Computing Estimation
* **Secure Password Generator:**
  * Generates robust 16-character passwords based on custom user input seeds.
  * Automatic inclusion of special characters, numbers, uppercase, and lowercase letters.
* **One-Click Copy:** Instant clipboard integration with feedback animations.
* **Cyberpunk Aesthetic:** Immersive dark UI featuring animated background rain and glowing particle effects.
